# 硕珍的手机

《花样年华》同人叙事作品（非官方）。一部停在 2022 年 5 月 21 日深夜的手机。解锁密码：0612。
纯 HTML / CSS / JavaScript，不需要安装或编译。

## 怎么打开

网站地址：<https://pilicat913.github.io/seokjin-phone/>（GitHub Pages，推送到 main 后自动更新）。

也可以把整个文件夹上传到任意静态网站托管，打开 `index.html` 即可。

本地预览时，建议在文件夹里运行一个简单的服务器，例如：

```
python3 -m http.server 8000
```

然后在浏览器打开 `http://localhost:8000`。
（直接双击 `index.html` 大部分功能也能用，但语音、图片路径在某些浏览器里会受限制。）

## 文件结构

```
index.html          页面骨架（状态栏、各层容器），按顺序加载下面的脚本
css/
  phone.css         手机外壳、锁屏、密码、主屏幕、通知横幅、页面切换动画
  chat.css          聊天应用（KakaoTalk 版式）
  ios.css           其他系统应用：备忘录、电话、信息、日历、地图、浏览器、照片、时钟、设置、相机，以及来电和闹钟全屏
js/
  assets.js         素材槽位表：壁纸、应用图标、头像、聊天图片、表情、语音、相册（全部在这里填路径）
  story.js          全部剧情数据：聊天、短信、通话记录、联系人、备忘录、日历、地图、搜索记录、闹钟
  ui.js             通用工具：时间格式、图标、头像、合成音效、横幅通知、会话存储
  chat.js           聊天应用的界面和逻辑
  apps.js           其余系统应用的界面和逻辑
  events.js         剧情事件：泰亨来电 → “…明天见” → 03:30 闹钟 → 屏幕熄灭
  app.js            手机外壳：锁屏、解锁、主屏幕、打开/关闭应用、侧键锁屏
assets/
  icons/            应用图标（SVG，已放好）
  sounds/           katalk.mp3 新消息提示音、departure-alarm.wav 闹钟音
  wallpaper/ avatars/ photos/ chat/ stickers/ voices/   你自己的素材（目前为空）
```

## 常见修改

**换素材**：把文件放进 `assets/` 下对应文件夹，然后在 `js/assets.js` 里把 `null` 改成路径，例如
`lock: 'assets/wallpaper/lock.jpg'`。每个槽位后面的注释写了建议放什么。

**改聊天**：都在 `js/story.js` 的 `rooms` 里。每条消息格式是
`['时间', '发送者', 内容, 选项]`：

- 时间：`'05-21 23:12'`（默认 2022 年），或 `'2019-06-12 19:42'`
- 发送者：`me` 是硕珍；`nj` 南俊，`yg` 玧其，`hs` 号锡，`jm` 智旻，`th` 泰亨，`jk` 柾国，`gm` 外婆，`sys` 系统消息
- 内容：一段文字；或 `{ photo: '槽位名' }`、`{ sticker: '槽位名' }`、`{ voice: '槽位名', dur: '0:07' }`、
  `{ call: 'voice', dur: '12:04' }`、`{ link: { title: '标题', site: '来源' } }`、`{ sys: '系统提示' }`、`{ deleted: true }`
- 选项：`{ u: 2 }` 显示未读人数；`{ unread: true }` 表示硕珍还没看（会出现在锁屏和角标上）

同一个房间里的消息必须按时间先后排列。

**改密码**：`js/story.js` 顶部的 `passcode: '0612'`。

**改冻结时间**：`js/story.js` 顶部的 `now`。

**时间**：手机里的时间跟着现实走，每过一分钟跳一格，刷新后接着走。
- 23:53 泰亨来电：打开备忘录那条笔记 5 秒后打来；没看笔记的话，时间走到 23:53 也会自己打来。来电之前时间最多走到 23:53。
- 来电之后时间可以过零点，一直走到 03:29；闹钟一响直接跳到 03:30。

**返回主屏幕**：点或上滑底部横条；在应用最外层从屏幕左边缘往右滑；电脑上按 Esc；手机或浏览器自带的“返回”也可以（先退一页，退到底回主屏幕）。

**聊天输入框**：可以打字发送，但消息会显示红色感叹号（发送失败），可以重发或删除，刷新后消失，不影响剧情。

**照片地点**：`js/assets.js` 相册里每张的 `place` 是点开照片时顶部显示的地点，不填就只显示日期。

**剧情顺序**（`js/events.js`）
- 打开备忘录里那条笔记 5 秒后（或时间走到 23:53），泰亨来电（接听约 6 秒自动结束）；挂断 7 秒后收到“…明天见”。
- 桌面 7 个应用 + Dock 4 个应用（共 11 个，天气小组件不算）都打开过一次后，3 秒进入清晨：03:30 闹钟响。重复打开同一个应用不重复计数，刷新不丢进度。来电进行中或刚挂断时会等一等，不会打断。
  要改必需的应用，改 `REQUIRED` 列表；要改等待时间，改 `scheduleMorning` 里的 `3000`。
- 闹钟“稍后提醒”是真实的 9 分钟；“停止”后回到 5 月 22 日的锁屏，7 秒后屏幕熄灭。

**声音**：设置 → 声音与触感，可以试听、调音量、静音。换提示音就替换 `assets/sounds/` 里的文件，或改 `js/assets.js` 的 `sounds`。

**重置进度**：进度存在浏览器的会话存储里，关掉标签页就会清空。
如果改了剧情后想让已经打开过的人也从头开始，把 `js/ui.js` 里的 `KEY = 'sj-phone-v9'` 改成新名字即可。
